# V4.0 浏览器实测截图

用 Playwright + Chromium 在 420×860 视口（iPhone 尺寸）实际跑出来的界面，不是设计稿。

| 截图 | 说明 |
|------|------|
| `01-语音条.png` | 语音条：波形 + 时长 8"，点击展开灰色转写框；下方是角色回复 |
| `02-关系图谱.png` | SVG 力导向图：粉色粗线=夫妻，蓝色细线=亲子，节点圆点进角色详情 |
| `03-朋友圈话题.png` | 朋友圈顶部 `#话题#` 与 `📍打卡` 筛选条，卡片正文含话题与位置 |
| `04-表情面板.png` | 「+」菜单里的表情面板，12 个内置表情 |
| `05-聊天列表.png` | 通讯录列表：名字后的 💍❤️⭐👶 与职级徽章 `P2` |

> 截图中部分 emoji 显示为方框，是容器环境缺少 emoji 字体所致；Windows/macOS/Android/iOS 均正常显示。
