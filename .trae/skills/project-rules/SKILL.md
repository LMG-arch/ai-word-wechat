# AI社交世界项目开发规范

本规范用于指导AI社交世界（仿微信界面）Android应用的开发。

## 1. 技术选型规范

开发时必须使用以下技术栈：

| 层级 | 技术选型 | 说明 |
|------|---------|------|
| UI框架 | Jetpack Compose | 现代声明式UI |
| 主数据库 | Neo4j + Graphiti | 时间感知图数据库 |
| 本地缓存 | Room SQLite | 配置、临时数据 |
| 网络层 | Retrofit + OkHttp | AI API调用 |
| 异步 | Kotlin Coroutines + Flow | 响应式编程 |
| 依赖注入 | Dagger Hilt | 模块解耦 |
| 图片加载 | Coil | Compose原生支持 |
| 图表 | MPAndroidChart | 技能可视化 |

## 2. 代码风格要求

- **简洁原则**：使用最简洁的代码，不产生臃肿代码
- **禁止过度注释**：除非必要，不添加注释
- **遵循现有规范**：编辑代码时先了解现有代码风格和模式
- **安全优先**：不引入暴露密钥或日志泄露 secrets 的代码

## 3. 功能完整性要求

根据开发文档，以下核心功能必须完整实现：

### 3.1 AI角色管理系统
- 角色创建与配置（昵称、性别、年龄、职业、性格、头像）
- 智能头像生成（结合人设描述生成）
- API配置体系（支持多服务商切换、备用机制）
- 角色生命周期与成长系统
- 时间流逝机制（1-30倍速）
- 年龄阶段划分（儿童/青少年/青年/中年/老年）
- 角色自主更新机制（头像、签名）

### 3.2 记忆系统
- Graphiti + Neo4j 时间知识图谱
- 双时态模型（valid_from, valid_to）
- 记忆结构（时间戳、重要性、情感、相关实体）
- 记忆召回流程（向量检索 -> 重排 -> 上下文注入）
- 时间衰减函数
- 历史状态查询

### 3.3 关系与社交系统
- 亲密度系统（0-100，动态变化）
- 关系状态阈值
- 朋友圈机制
- 私人群聊

### 3.4 任务系统
- 任务类型（文本/图像/代码/调研/设计）
- 个人任务流程
- 公司任务流程
- 任务管理器
- 图像生成质量要求（史诗感、禁止二次元）

### 3.5 反思引擎
- 反思触发时机
- 反思报告结构
- 技能系统

### 3.6 公司系统
- 公司创建条件与流程
- 公司结构（法人、成员）
- 公司知识库
- 资金管理

### 3.7 经济系统
- 资金模型
- 贷款机制
- 破产机制

### 3.8 日程系统
- 每日日程生成
- 动态调整

### 3.9 地图系统
- 世界地图
- 位置历史
- 相遇检测

### 3.10 仿微信界面
- 底部导航栏：聊天 | 通讯录 | 群聊 | 任务 | 发现 | 我
- 聊天模块
- 通讯录模块
- 角色详情页
- 群聊列表/详情页
- 任务详情页
- 公司详情页
- 发现模块（朋友圈）
- 个人中心
- 日志面板

## 4. 数据模型规范

### 4.1 节点类型
- Character（角色）
- Company（公司）
- Task（任务）
- Location（位置）
- Reflection（反思）

### 4.2 关系类型
- FRIEND_WITH（好友关系）
- WORK_AT（工作关系）
- POSTED（任务提交）
- LOCATED_AT（位置历史）
- HAS_MEMORY（反思记忆）
- PARTICIPATED_IN（任务参与）

## 5. API集成规范

### 5.1 模型类型
| 模型类型 | 用途 |
|---------|------|
| 语言模型 | 对话、文本生成、反思报告 |
| 图像模型 | 绘图、头像生成 |
| 向量模型 | 记忆检索 |
| 重排模型 | 记忆排序 |

### 5.2 调用规范
- 异步处理，不阻塞UI
- 超时控制（连接5秒，读取30秒）
- 重试策略（失败重试2次，连续失败3次切换备用）
- 密钥加密存储

## 6. 性能要求

| 指标 | 要求 |
|------|------|
| 冷启动 | <3秒 |
| 内存占用 | <200MB |
| 帧率 | >50fps |
| AI并发 | 最大3 |
| 记忆检索 | <500ms |

## 7. 开发环境

- 操作系统：Windows
- 开发语言：Kotlin
- 目标平台：Android
- 最低SDK：24（Android 7.0）

## 8. 触发条件

本规范应在以下情况自动触发：
1. 用户要求开发或修改Android应用代码
2. 用户要求添加新功能
3. 用户要求修复bug
4. 用户询问技术选型或架构
5. 用户要求代码审查
